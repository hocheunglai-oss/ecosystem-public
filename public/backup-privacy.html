ECO Nightly Backups

Privacy notice · 21 October 2026

ECO Nightly Backups is a private tool for authorised ECO operators. It is designed to protect ECO’s database and stored documents by keeping encrypted recovery copies in a designated private Google Drive folder.

This page describes the backup design and Google connection. It does not confirm that scheduled backups are active.

Information handled

A backup contains ECO database records, including business, account and authentication data, together with stored documents. The authorised backup runner reads this information to prepare the recovery copy.

The tool checks the connected Google account’s email address, storage quota, and the ownership and permissions of its backup folder and files. Backup metadata includes the backup date, file size, integrity checksum and verification status.

Google Drive access

The Google connection uses the drive.file permission, covering files created by this app or explicitly made available to it. The tool works only with its designated backup folder and managed backup files. It does not access unrelated Drive files.

It uploads encrypted archives, downloads them to verify their integrity, and manages retention. Backups must remain private to the authorised operator account; the tool does not share or publish them.

Encryption and recovery

Backup contents are encrypted before upload to Google Drive. The private recovery key is kept separately, outside Google Drive and GitHub. The backup runner uses only the public encryption key. Restoring a backup requires the private recovery key.

Google stores the encrypted files and their metadata. GitHub Actions runs the backup process using protected credentials. Temporary unencrypted working files are removed after processing.

Retention and disconnection

The retention policy keeps the latest five verified Hong Kong backup dates. An older managed archive is moved to Google Drive’s trash only after the current backup is verified and at least five newer verified dates remain. Other files and recovery materials are excluded from this cleanup.

Trashed files remain recoverable until Google’s automatic expiry or earlier deletion by the account owner. Drive currently deletes trash after 30 days, and trashed files continue to use storage quota.

Revoking the app’s Google account access stops future backups. It does not delete existing backup files; the account owner can manage those files directly in Google Drive.
